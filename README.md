# Click OS

**Sistema de Gestão de Manutenção**

O Click OS é um projeto de desenvolvimento de software voltado à gestão e organização de atividades de manutenção. O objetivo é desenvolver uma aplicação que facilite o acompanhamento de equipamentos, ordens de serviço e históricos de manutenção.

O projeto está sendo desenvolvido de forma colaborativa por Sean e Duda, unindo conhecimentos de desenvolvimento de sistemas, manutenção e automação.

## Objetivos do projeto

* Organizar informações sobre equipamentos e ativos.
* Registrar e acompanhar ordens de serviço.
* Manter um histórico das manutenções realizadas.
* Facilitar o planejamento e o acompanhamento das atividades de manutenção.
* Explorar futuras possibilidades de integração com sensores e dispositivos de automação.

## Funcionalidades planejadas

* [ ] Cadastro e gerenciamento de equipamentos.
* [ ] Registro e acompanhamento de ordens de serviço.
* [ ] Histórico de manutenções.
* [ ] Organização de manutenções preventivas e corretivas.
* [ ] Painel para acompanhamento das atividades.
* [ ] Avaliação de futuras integrações com sensores e IoT.

## Tecnologias

As tecnologias serão definidas e documentadas conforme a evolução do projeto.

Possíveis tecnologias em estudo:

* **Python:** desenvolvimento da lógica e das funcionalidades do sistema.
* **MySQL:** armazenamento e gerenciamento de dados.
* **HTML, CSS e JavaScript:** desenvolvimento da interface web.
* **Arduino e sensores:** possibilidades futuras de automação e monitoramento.

## Desenvolvimento

Este repositório será utilizado para armazenar o código-fonte, documentar decisões técnicas, acompanhar a implementação das funcionalidades e registrar a evolução do Click OS.
